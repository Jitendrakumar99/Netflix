
# Netflix India Clone

This is a Netflix India clone built with React and Vite. It simulates the Netflix landing page experience, including sign up, login, and feature highlights. The project demonstrates modern React development practices and UI design.

## Features

- Responsive Netflix-style homepage
- Sign up and login functionality (localStorage-based)
- Language selection (English/Hindi)
- Feature sections: Watch on TV, Download for offline, Enjoy on any device
- FAQ section with common Netflix questions
- Footer with useful links

## Tech Stack

- React
- Vite
- CSS (custom, no frameworks)
- LocalStorage for simple auth

## Installation

1. Clone the repository:
	```powershell
	git clone https://github.com/Jitendrakumar99/Netflix.git
	cd Netflix
	```
2. Install dependencies:
	```powershell
	npm install
	```
3. Start the development server:
	```powershell
	npm run dev
	```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage

- Click "Sign Up" to create a new account.
- Login with your credentials (stored in localStorage).
- Explore the homepage features and sections.

## Project Structure

- `src/components/` - React components for each section
- `public/` - Static assets (images, videos)
- `App.jsx` - Main app logic and routing
- `index.html` - Entry point
